# Review checklist

Before merging `agentic-comprehensive-rebuild` into `main`, preview the branch in Streamlit Cloud using `app/main.py` and complete this short review:

1. Load the synthetic qualification case.
2. Confirm the structured case representation.
3. Review guideline evidence and any retrieved molecular/FDA safety candidates.
4. Complete the evidence-attestation gate.
5. Run the governed analysis.
6. Confirm the right-side inspector exposes integrity, missing information, runtime evidence state, routed specialists, red-team/consensus state, audit events, and brief release state.
7. Review the full decision brief, alternatives, prerequisites, uncertainty, trials, safety, provenance, and unresolved questions.
8. Test governed follow-up chat.
9. Download the PDF brief.
10. Review Validation & Scope, Architecture, and Scientific Scope pages.

Do not treat a successful software preview as clinical validation or clinical release.
